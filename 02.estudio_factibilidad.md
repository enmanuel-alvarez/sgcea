# Estudio de Factibilidad: SGCEA
## Sistema de Gestión y Control Escolar-Académico

**Versión:** 1.0.0  
**Fecha:** Junio 2026  

---

## 1. Plataforma Instalada (¿Qué infraestructura existe hoy?)

Esta sección describe el hardware y software con el que cuenta la institución actualmente (la base sobre la cual se montará el sistema en su fase local).

- **Hardware Existente:** Computadoras de escritorio en la oficina de administración, dirección y control de estudios (generalmente procesadores estándar como Intel Core i3/i5 o equivalentes, con 4GB u 8GB de RAM).
- **Software Existente:** Sistemas operativos Windows (usualmente Windows 10 Home o Pro). Navegadores web ya instalados como Google Chrome, Microsoft Edge o Mozilla Firefox.
- **Red:** Existencia de una red local interna (LAN) cableada o vía Wi-Fi dentro de las oficinas administrativas de la escuela.

**Conclusión de factibilidad:** Al ser el SGCEA una aplicación web, la plataforma instalada es 100% compatible porque cualquier computadora con un navegador web moderno podrá acceder al sistema de forma local sin necesidad de renovar las PCs de la escuela.

---

## 2. Plataforma Prospectiva (¿Qué entorno técnico se necesita desplegar?)

Aquí se detalla el entorno de software y configuración técnica que se desarrollará e instalará para que el SGCEA funcione sobre la plataforma existente. Es el "ecosistema de desarrollo y ejecución".

- **Servidor Local (Backend & Servidor Web):** Arquitectura basada en el stack WAMP/LAMP/MAMP. Se utilizará Apache como servidor web y PHP 8.x como lenguaje de programación interpretado en el lado del servidor.
- **Gestor de Base de Datos (Persistencia):** MySQL configurado localmente en la máquina que actuará como servidor central de la escuela.
- **Componentes de Desarrollo (Estructura Interna):** Código organizado bajo el patrón MVC, clases en POO y uso del archivo `.htaccess` para el enrutamiento de URLs limpias mediante un Front Controller personalizado.
- **Entorno de Staging:** Hosting gratuito InfinityFree con PHP 8.3 y MySQL para pruebas de integración. Sincronización mediante `git-ftp` desde repositorio GitHub.
- **Client-Side (Frontend):** Inclusión del framework Bootstrap 5 y Bootstrap Icons vía CDN dentro del código del proyecto para que la interfaz se adapte a las pantallas existentes sin requerir software de diseño adicional.

## 3. Plataforma de Inversión (¿Qué se necesita adquirir a corto y mediano plazo?)

Representa el análisis de costos e infraestructura que la institución debe asumir para el desarrollo, puesta en marcha y la futura escalabilidad a internet. Al ser un proyecto académico enfocado en software libre, la inversión es sumamente baja, lo que hace al proyecto altamente factible.

### Inversión a Corto Plazo (Fase Local / Desarrollo)

- **Software:** $0 (Costo Cero). Al utilizar tecnologías de código abierto (Open Source) como PHP, MySQL, Apache y Bootstrap, la institución no debe pagar licencias de software comerciales.
- **Hardware:** $0. Se designará una de las computadoras existentes con mejores prestaciones (por ejemplo, la de Administración con Windows 10 Pro) para que actúe temporalmente como servidor local de la base de datos durante la jornada laboral.
- **Control de Versiones y Staging:** $0. GitHub ofrece repositorios privados gratuitos para equipos. El entorno de staging se aloja en InfinityFree sin costo.

### Inversión a Mediano/Largo Plazo (Fase Cloud / Escalabilidad)

- **Dominio Web:** Compra de una dirección web única para el sistema (ej. `www.sgcea-institucion.com`), con un costo estimado de $10 a $15 anuales.
- **Alojamiento Web (Hosting Cloud o VPS):** Contratación de un servidor en internet que soporte PHP 8 y MySQL, con un costo estimado de $40 a $80 anuales (ajustado para soportar el SLA y la concurrencia definidos previamente).
- **Seguridad:** Certificado SSL (HTTPS) para el cifrado de datos en internet (generalmente incluido de forma gratuita como Let's Encrypt en el hosting).

Con este enfoque, el Estudio de Factibilidad deja claro que el SGCEA es económicamente viable (inversión inicial cero por usar tecnologías libres) y técnicamente realizable sobre la infraestructura actual de la escuela.
