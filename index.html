Manual Técnico y de Desarrollador - SGCEA

Arquitectura MVC Nativo en PHP 8.3 • Base de Datos MySQL (InnoDB, UTF8MB4) • Tailwind CSS v3

1. Arquitectura General y Patrón de Diseño

El sistema SGCEA está construido siguiendo el patrón de diseño Modelo-Vista-Controlador (MVC) desacoplado en PHP Orientado a Objetos (POO):

  • Clean Architecture: Lógica de negocio en servicios (`app/Models/Services/`), datos en repositorios (`app/Models/Repositories/`).
  • Singleton Pattern: Conexión centralizada PDO vía `Src\Core\Database`.
  • Front Controller Pattern: Punto de entrada único `public/index.php` gestionado por `Src\Core\Router`.
  • Variables de Entorno: Carga dinámica mediante `Src\Core\Env` e integración con helper `env()`.

2. Componentes del Núcleo (`core/`)

Autoloader.php

Registra autoloader PSR-4 para el namespace raíz `Src\`, enrutando controladores, servicios y modelos.

Database.php

Patrón Singleton con PDO nativo, desactivación de emulación de prepared statements y manejo estricto de excepciones.

Router.php

Enrutador de URLs limpias con parámetros dinámicos `{id}`, verificación de sesión y permisos ACL pre-ejecución.

Security.php

Sanitización XSS con `e()`, generación/validación de tokens anti-CSRF y cifrado BCRYPT con costo 10.

RateLimiter.php

Control de intentos fallidos de inicio de sesión por dirección IP en tabla `intentos_login` contra fuerza bruta.

Controller.php

Clase base abstracta con helpers de renderizado de vistas en layouts, respuestas JSON y redirecciones HTTP.

Manual de Usuario - SGCEA

Guía Operativa de Uso para Administradores, Docentes y Estudiantes

1. Inicio de Sesión y Autenticación

Ingrese a la plataforma mediante su **Cédula de Identidad** o **Correo Electrónico** y contraseña asignada. El sistema cuenta con protección automática de *Rate Limiting* que suspende temporalmente el acceso tras 5 intentos fallidos.

  • • Métricas Globales: Panel de control con resúmenes agregados en tiempo real.
  • • Gestión ACL: Asignación individual de permisos de la matriz de 48 opciones.
  • • Gestión Académica: Creación de materias, secciones, docentes y alumnos.
  • • Respaldos: Generación e importación de volcados de base de datos SQL/JSON.
