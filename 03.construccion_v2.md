## 1. INTRODUCCIÓN Y ALCANCE

### 1.1 Propósito del Sistema

SGCEA es un sistema de información web diseñado para digitalizar y centralizar los procesos académicos y administrativos de instituciones educativas, eliminando por completo la dependencia de archivos físicos o herramientas ofimáticas descentralizadas. El sistema se fundamenta en los principios de **centralización absoluta**, **eficiencia operativa** y **acceso controlado por permisos individuales (ACL)**.

### 1.2 Objetivos del Sistema (Reforzados)

| Objetivo | Descripción | Métrica de Éxito |
|----------|-------------|------------------|
| **Centralización** | Toda la información reside en una única base de datos relacional, sin exportaciones a Excel que fragmenten los datos. | 100% de datos en el sistema, 0 exportaciones a Excel. |
| **Automatización** | Procesos como cálculo de promedios, generación de constancias y reportes se realizan automáticamente. | 90% de procesos automatizados. |
| **Accesibilidad** | Acceso desde cualquier dispositivo con navegador, con interfaz adaptable (Bootstrap 5). | Disponibilidad 99.5% en horario laboral. |
| **Seguridad Granular** | Cada usuario tiene permisos específicos (ACL), no roles genéricos. | 0 brechas de seguridad. |
| **Rendimiento** | Tiempos de respuesta < 1s para consultas simples, < 3s para reportes complejos. | Cumplimiento SLA. |

### 1.3 Cambios Arquitectónicos Principales (vs. Versión 1.0)

| Aspecto | Versión 1.0 | Versión 2.0 (Final) |
|---------|-------------|----------------------|
| **Control de acceso** | RBAC (Roles: Admin, Docente, Estudiante) | **ACL por usuario** (permisos individuales) |
| **Exportación de datos** | CSV, Excel, PDF (TCPDF) | **Solo PDF mediante impresión del navegador** (sin librerías externas) |
| **Capa de datos** | Entities + Repositories + Services | **Repositories + Services** (eliminación de Entities) |
| **Consultas a BD** | Bucle N+1 en calificaciones | **JOIN optimizados** (una sola consulta) |
| **Rate Limiting** | Archivo JSON | **Tabla en BD** |
| **Dashboards** | Consultas en tiempo real | **Caché con tablas resumen** |
| **Validación de permisos** | En cada método del controlador | **En el Router** (asociado a rutas) |
| **Interfaz visual** | Bootstrap 5 estándar | Bootstrap 5 + **DataTables**, **Toasts**, **modo oscuro**, **sidebar dinámico por ACL** |

### 2.2 Flujo de Petición HTTP (Optimizado con ACL en Router)

1. Petición HTTP → `public/index.php` (Front Controller).
2. `index.php` → `bootstrap/app.php` (carga configuración, sesión, autoloader).
3. Router (`core/Router.php`) analiza URL y método HTTP.
4. Router busca ruta en `config/routes.php`, donde cada ruta tiene asociado un **permiso** requerido.
5. Router verifica autenticación y, si existe permiso requerido, valida que el usuario lo tenga (usando `$_SESSION['usuario_permisos']`).
6. Si no autenticado → redirige a login. Si no tiene permiso → error 403.
7. Router instancia el Controlador (inyección de dependencias) y ejecuta el método.
8. Controlador llama a los Services correspondientes.
9. Services usan Repositories para acceder a datos (consultas optimizadas con JOIN).
10. Repositories retornan arrays asociativos.
11. Controlador renderiza Vista con datos.
12. Vista genera HTML (con DataTables, Toasts, etc.) y lo envía al cliente.

### 2.3 Componentes Core Refactorizados

#### 2.3.1 Router con Verificación de Permisos (ACL Nativo)

```php
// core/Router.php
class Router {
    private array $rutas = [];

    public function get(string $ruta, array $controladorMetodo, ?string $permiso = null): void {
        $this->rutas['GET'][$ruta] = [
            'controlador' => $controladorMetodo[0],
            'metodo'      => $controladorMetodo[1],
            'permiso'     => $permiso
        ];
    }

    public function post(string $ruta, array $controladorMetodo, ?string $permiso = null): void {
        $this->rutas['POST'][$ruta] = [
            'controlador' => $controladorMetodo[0],
            'metodo'      => $controladorMetodo[1],
            'permiso'     => $permiso
        ];
    }

    public function resolver(string $url, string $metodoHttp): void {
        $ruta = $this->rutas[$metodoHttp][$url] ?? null;
        if (!$ruta) {
            $this->lanzar404();
            return;
        }

        // Verificar autenticación
        if (!isset($_SESSION['usuario_id'])) {
            header('Location: index.php?url=/');
            exit;
        }

        // Verificar permiso (ACL)
        if ($ruta['permiso'] && !$this->tienePermiso($ruta['permiso'])) {
            http_response_code(403);
            require __DIR__ . '/../app/Views/errors/403.php';
            exit;
        }

        // Instanciar controlador (con DI)
        $nombreControlador = "Src\\Controllers\\" . $ruta['controlador'];
        if (class_exists($nombreControlador)) {
            $controlador = $this->container->resolver($nombreControlador);
            if (method_exists($controlador, $ruta['metodo'])) {
                $controlador->{$ruta['metodo']}();
                return;
            }
        }
        $this->lanzar404();
    }

    private function tienePermiso(string $permiso): bool {
        return isset($_SESSION['usuario_permisos'][$permiso]) && $_SESSION['usuario_permisos'][$permiso] === true;
    }
}
```

#### 2.3.3 Database y Rate Limiting en BD

```php
// core/Database.php (sin cambios significativos)
// core/RateLimiter.php (nuevo)
class RateLimiter {
    private PDO $db;
    private int $maxAttempts = 5;
    private int $windowMinutes = 15;

    public function __construct(PDO $db) {
        $this->db = $db;
    }

    public function isLimited(string $ip): bool {
        $sql = "SELECT COUNT(*) FROM intentos_login WHERE ip_address = :ip AND fecha_intento > DATE_SUB(NOW(), INTERVAL :window MINUTE)";
        $stmt = $this->db->prepare($sql);
        $stmt->execute([':ip' => $ip, ':window' => $this->windowMinutes]);
        return $stmt->fetchColumn() >= $this->maxAttempts;
    }

    public function registerAttempt(string $ip): void {
        $sql = "INSERT INTO intentos_login (ip_address) VALUES (:ip)";
        $stmt = $this->db->prepare($sql);
        $stmt->execute([':ip' => $ip]);
    }

    public function resetAttempts(string $ip): void {
        $sql = "DELETE FROM intentos_login WHERE ip_address = :ip";
        $stmt = $this->db->prepare($sql);
        $stmt->execute([':ip' => $ip]);
    }
}
```

## 4. LÓGICA DE NEGOCIO Y ALGORITMOS (REFACTORIZADOS)

### 4.1 Optimización del Cálculo de Notas (Eliminación de N+1)

**Antes:** Bucle por cada estudiante y evaluación (N+1 consultas).  
**Ahora:** Una sola consulta JOIN con agregación.

```php
// app/models/Repositories/CalificacionRepository.php
public function obtenerNotasPorSeccionYMateria(int $id_seccion, int $id_materia, array $evaluaciones): array {
    // Construir dinámicamente las columnas CASE para cada evaluación
    $caseColumns = '';
    foreach ($evaluaciones as $eval) {
        $caseColumns .= "MAX(CASE WHEN pe.id_plan = {$eval['id_plan']} THEN c.valor_obtenido END) AS nota_{$eval['id_plan']}, ";
    }
    $caseColumns .= "ROUND(AVG(c.valor_obtenido * pe.ponderacion / 100), 2) AS nota_final";

    $sql = "SELECT e.id_estudiante, e.nombres, e.apellidos, e.cedula_identidad,
                   $caseColumns
            FROM estudiantes e
            INNER JOIN inscripciones i ON e.id_estudiante = i.id_estudiante
            LEFT JOIN calificaciones c ON e.id_estudiante = c.id_estudiante
            LEFT JOIN planes_evaluacion pe ON c.id_plan = pe.id_plan
            WHERE i.id_seccion = :id_seccion AND pe.id_asignacion = (
                SELECT id_asignacion FROM asignaciones WHERE id_materia = :id_materia AND id_seccion = :id_seccion LIMIT 1
            )
            GROUP BY e.id_estudiante";

    $stmt = $this->db->prepare($sql);
    $stmt->execute([':id_seccion' => $id_seccion, ':id_materia' => $id_materia]);
    return $stmt->fetchAll(PDO::FETCH_ASSOC);
}
```

// AuthController.php
public function procesarLogin(): void {
    // Validar CSRF
    // Obtener IP
    $rateLimiter = new RateLimiter($this->db);
    if ($rateLimiter->isLimited($ip)) {
        $this->render('auth/login', ['error' => 'Demasiados intentos fallidos. Espere 15 minutos.']);
        return;
    }
    // Autenticar
    $usuario = UsuarioService::autenticar($login, $password);
    if ($usuario) {
        $rateLimiter->resetAttempts($ip);
        $_SESSION['usuario_id'] = $usuario['id_usuario'];
        $_SESSION['usuario_permisos'] = PermisoService::obtenerPermisosUsuario($usuario['id_usuario']);
        // Redirigir
        header('Location: index.php?url=admin/dashboard');
    } else {
        $rateLimiter->registerAttempt($ip);
        $this->render('auth/login', ['error' => 'Credenciales incorrectas']);
    }
}
