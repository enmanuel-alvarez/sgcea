# Estudio de Factibilidad: SGCEA

## Sistema de Gestión y Control Escolar-Académico

---

## 1. Plataforma Instalada (¿Qué infraestructura existe hoy?)

Esta sección describe el hardware y software con el que cuenta la institución actualmente (la base sobre la cual se montará el sistema en su fase local).

- **Hardware Existente:** Computadoras de escritorio en la oficina de administración, dirección y control de estudios (generalmente procesadores estándar como Intel Core i3/i5 o equivalentes, con 4 GB u 8 GB de RAM). No se requiere equipo especializado ni servidores dedicados.

- **Software Existente:** Sistemas operativos Windows (usualmente Windows 10 Home o Pro). Navegadores web ya instalados como Google Chrome, Microsoft Edge o Mozilla Firefox (versiones actualizadas). No se necesitan licencias adicionales de software.

- **Red:** Existencia de una red local interna (LAN) cableada o vía Wi-Fi dentro de las oficinas administrativas de la escuela. En el futuro, la conexión a internet será necesaria para el despliegue en la nube.

**Conclusión de factibilidad:** Al ser el SGCEA una aplicación web, la plataforma instalada es 100% compatible porque cualquier computadora con un navegador web moderno podrá acceder al sistema de forma local sin necesidad de renovar las PCs de la escuela. La carga de procesamiento recae en el servidor (que puede ser una de las PCs existentes), no en los equipos clientes.

## 2. Plataforma Prospectiva (¿Qué entorno técnico se necesita desplegar?)

Aquí se detalla el entorno de software y configuración técnica que se desarrollará e instalará para que el SGCEA funcione sobre la plataforma existente. Es el "ecosistema de desarrollo y ejecución".

- **Servidor Local (Backend & Servidor Web):** Arquitectura basada en el stack WAMP/LAMP/MAMP. Se utilizará Apache como servidor web y PHP 8.x como lenguaje de programación interpretado en el lado del servidor. Se designará una de las computadoras existentes (preferiblemente la de mayor capacidad) para que actúe como servidor local durante el horario laboral.

- **Gestor de Base de Datos (Persistencia):** MySQL configurado localmente en la máquina que actuará como servidor central. La base de datos incluirá tablas para la gestión de permisos individuales (ACL), control de intentos de login (rate limiting) y caché de dashboards para optimizar el rendimiento.

- **Componentes de Desarrollo (Estructura Interna):** Código organizado bajo el patrón MVC, clases en POO, uso del archivo `.htaccess` para el enrutamiento de URLs limpias mediante un Front Controller personalizado que verifica permisos a nivel de ruta. Las consultas a la base de datos se optimizan con JOIN para evitar el problema N+1.

- **Entorno de Staging:** Hosting gratuito InfinityFree con PHP 8.3 y MySQL para pruebas de integración. Sincronización mediante `git-ftp` desde repositorio GitHub.

- **Generación de Documentos:** No se requieren librerías externas de PDF (como TCPDF). La emisión de constancias, carnets y boletines se realiza mediante vistas HTML especiales con hojas de estilo CSS para impresión (`@media print`). El navegador del cliente se encarga de generar el PDF mediante su diálogo de impresión, lo que simplifica el mantenimiento y reduce la carga del servidor.

- **Client-Side (Frontend):** Inclusión del framework Tailwind CSS v3 y Bootstrap Icons vía CDN. Mejoras visuales como DataTables para listados grandes, Toasts para notificaciones no intrusivas, y un sidebar dinámico que se adapta a los permisos del usuario. Se incluye también un toggle de modo oscuro/claro para mejorar la experiencia de usuario.

- **Seguridad y Control de Acceso:** El sistema utiliza un modelo de Listas de Control de Acceso (ACL) donde cada usuario tiene permisos específicos asignados directamente, sin depender de roles fijos. El rate limiting se gestiona mediante una tabla en la base de datos, y todas las acciones quedan registradas en una tabla de auditoría.

## 3. Plataforma de Inversión (¿Qué se necesita adquirir a corto y mediano plazo?)

Representa el análisis de costos e infraestructura que la institución debe asumir para el desarrollo, puesta en marcha y la futura escalabilidad a internet. Al ser un proyecto académico enfocado en software libre, y con las decisiones arquitectónicas adoptadas, la inversión es sumamente baja, lo que hace al proyecto altamente factible.

### Inversión a Corto Plazo (Fase Local / Desarrollo)

- **Software:** $0 (Costo Cero). Al utilizar tecnologías de código abierto (Open Source) como PHP, MySQL, Apache y Tailwind CSS, la institución no debe pagar licencias de software comerciales. La generación de documentos se realiza mediante el navegador, sin necesidad de librerías externas de pago.

- **Hardware:** $0. Se designará una de las computadoras existentes con mejores prestaciones (por ejemplo, la de Administración con Windows 10 Pro) para que actúe temporalmente como servidor local de la base de datos durante la jornada laboral. No se requiere adquirir nuevo hardware.

- **Control de Versiones y Staging:** $0. GitHub ofrece repositorios privados gratuitos para equipos. El entorno de staging se aloja en InfinityFree sin costo.

- **Capacitación:** $0 (si es realizada por el equipo de desarrollo interno). La interfaz es intuitiva gracias a Tailwind CSS y las mejoras visuales, lo que reduce la curva de aprendizaje.

### Inversión a Mediano/Largo Plazo (Fase Cloud / Escalabilidad)

- **Dominio Web:** Compra de una dirección web única para el sistema (ej. `www.sgcea-institucion.com`), con un costo estimado de $10 a $15 anuales.

- **Alojamiento Web (Hosting Cloud o VPS):** Contratación de un servidor en internet que soporte PHP 8 y MySQL, con un costo estimado de $40 a $80 anuales (ajustado para soportar el SLA y la concurrencia definidos previamente). La arquitectura ligera (sin librerías pesadas de PDF) permite elegir planes de hosting más económicos.

- **Seguridad:** Certificado SSL (HTTPS) para el cifrado de datos en internet (generalmente incluido de forma gratuita como Let's Encrypt en el hosting). No se requieren firewalls adicionales ni soluciones de pago.

- **Mantenimiento:** Al ser un sistema con código limpio y bien documentado, y al eliminar dependencias externas (TCPDF, librerías de Excel), el costo de mantenimiento a largo plazo es mínimo, pudiendo ser asumido por el personal de TI interno.

### Resumen de Inversión Total Estimada

| Concepto | Corto Plazo | Mediano/Largo Plazo |
|----------|-------------|---------------------|
| Software | $0 | $0 |
| Hardware | $0 | $0 (hosting externo) |
| Dominio | $0 | $10 - $15 anuales |
| Hosting | $0 | $40 - $80 anuales |
| SSL | $0 | $0 (Let's Encrypt) |
| **Total** | **$0** | **$50 - $95 anuales** |

Con este enfoque, el Estudio de Factibilidad deja claro que el SGCEA es económicamente viable (inversión inicial cero por usar tecnologías libres), técnicamente realizable sobre la infraestructura actual de la escuela, y sostenible a largo plazo gracias a la simplicidad arquitectónica y la ausencia de dependencias externas pesadas.
